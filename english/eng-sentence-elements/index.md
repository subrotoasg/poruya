## Sentence Structure — The Big Picture

### Possible Sentence Patterns

একটি ইংরেজি sentence গঠিত হতে পারে এই কয়েকটি প্যাটার্নের যে কোনো একটিতে — প্রতিটিই সমান সঠিক।

- Sub + Verb + Obj / Complement / Extension
- Sub + Verb + Obj + Complement
- Sub + Verb + Obj + Extension
- Sub + Verb + Complement + Extension
- Sub + Verb + Obj + Complement + Extension
- Sub + Main Verb (শুধু এই দুটি দিয়েও সম্পূর্ণ sentence হয়)

> 💡 একটি sentence-এ একাধিক Extension পরপর চেইন হয়ে আসতে পারে — S+V+O+Ext+Ext+Ext...।

## Subject, Verb ও Object

### Subject

DEF : যার সম্পর্কে sentence-এ কিছু বলা হয় এবং যার উপর ভিত্তি করে verb-এর রূপ পরিবর্তিত হয়, তাকে subject বলে।

| | |
|---|---|
| Rice is eaten by us. | "Rice" = Sub (passive voice-এও subject-ই subject থাকে) |
| Himu saw a beautiful tall young white lady. | "Himu" = Sub |

> 💡 Subject-Verb Agreement — I/am, You/are, He-She-It/is।

### Subject হিসেবে কী কী বসতে পারে?

- Noun → Rana is a doctor.
- Pronoun → He is a doctor.
- Noun phrase → My brother is a doctor.
- Noun clause → That he is a doctor is known to all.
- Gerund (V1+ing) → Walking is a good form of exercise.
- Infinitive (to+V1) → To walk is a good form of exercise.

> 💡 Subject-পদে ব্যবহৃত হলে Gerund ও Infinitive দুটোই কাজ করে Noun-এর মতো।

### Verb

DEF : যে word দ্বারা কোনো কাজ করা, কোনো কিছু হওয়া, কারো কাছে/অধীনে কিছু থাকা বা অবস্থান করা বোঝায়, তাকে verb বলে।

| | |
|---|---|
| He studies regularly. | কাজ করা (does) |
| Shamim phoned the lass. | কাজ করলো (did) |
| Rupa is veridical. | হওয়া |
| Wasim has a laptop. | থাকা |
| Hena is in Jashore. | অবস্থান করা (থাকে) |

> 💡 "is"-এর আভিধানিক অর্থ = হয়/আছে।

### Object

DEF : কোনো sentence-এ verb-কে 'কি' বা 'কাকে' দ্বারা প্রশ্ন করলে যে অংশ পাওয়া যায়, তাকে object বলে।

- Noun → I know Rana.
- Pronoun → I helped her.
- Noun phrase → Rajib is my brother.
- Noun clause → I know that he is a doctor.
- Gerund (V1+ing) → I hate walking.
- Infinitive (to+V1) → He wanted to walk / to eat a burger.

## Double Object ও Objective Complement

### Double Object (Indirect + Direct Object)

Verb-কে কাকে/কি দিয়ে প্রশ্ন করলে কখনো কখনো দুটি object পাওয়া যায়।

Hena gave me a pencil. → "me" = Indirect Object (কাকে?); "a pencil" = Direct Object (কি?)

> 💡 এখানে me ≠ a pencil — তারা দুটি ভিন্ন সত্তা বোঝায়, এটাই Double Object-এর চিহ্ন।

| | |
|---|---|
| Rule 1 | গ্রহীতা + বস্তু — সরাসরি ক্রমে (Hena gave me a pencil) |
| Rule 2 | বস্তু + to + গ্রহীতা — ক্রম উল্টালে 'to' যুক্ত হয় (Hena gave a pencil to me) |

### Object + Objective Complement

Hena considered me a brother. → "me"=Obj, "brother"=Objective Complement — এখানে me = brother (দুটোই একই সত্তাকে বোঝায়)।

> 💡 মূল পার্থক্য : Double Object-এ Obj1 ≠ Obj2 (me ≠ a pencil); Object+Complement-এ Obj = Complement (me = brother)।

We elected him MP. → S+V+Obj+Comp (him = MP)

Active ↔ Passive রূপান্তরে Sub ও Obj নিজেদের মধ্যে ভূমিকা বদলায়।

## Transitive, Intransitive ও Linking Verb

### Transitive Verb (সকর্মক ক্রিয়া)

DEF : যে verb-এর object রয়েছে, তাকে transitive verb বলে। 'কি' বা 'কাকে' দিয়ে প্রশ্ন করলে verb-এর object পাওয়া যায়।

| | |
|---|---|
| She finished the task. | [S / T.V / Obj] — কি? |
| Hamim got the letter. | [S / T.V / Obj] — কি? |

### Intransitive Verb (অকর্মক ক্রিয়া)

DEF : যে verb-এর object থাকে না, তাকে intransitive verb বলে। 'কি'/'কাকে' দিয়ে প্রশ্ন করলে object পাওয়া যায় না।

| | |
|---|---|
| She cried loudly. | [S / I.T.V / Ext] — loudly একটি extension, object নয় |
| Hamim goes to college. | [S / I.T.V / Ext] — to college একটি extension, object নয় |

### Object বনাম Subjective Complement — তুলনা

Object : verb-এর পরের অংশটি subject-কে renaming করে না।

| | |
|---|---|
| Rupa takes tea. | [S/V/Obj] — Rupa ≠ tea |
| He plays chess. | [S/V/Obj] |

Subjective Complement : verb-এর পরের অংশটি subject-কেই describe/rename করে।

| | |
|---|---|
| Rupa looks cute. | [S/L.V/Sub-comp] — Rupa = cute |
| Honey tastes sweet. | [S/L.V/Sub-comp] — Honey = sweet |

### Subjective Complement

DEF : কোনো sentence-এ verb-এর পরের অংশটুকু যদি verb-এর আগের অংশটুকুকেই (subject) বুঝায়, তবে verb-এর পরের অংশটুকুকে Subjective Complement বলে।

Formula: S + L.V + Adj/N/Pronoun (sub-comp)

| | |
|---|---|
| We are students. | [S/L.V/sub-comp(N)] — We = students |
| We are talented. | [S/L.V/sub-comp(Adj)] |
| This pen is mine. | [S/L.V/sub-comp(Pronoun)] — মানে 'my pen' |

### Linking Verb (Copulative Verb / Copula)

DEF : যেসব verb-এর পরে subjective complement থাকে, তাদেরকে linking verb / copulative verb / copula বলে।

| | |
|---|---|
| Imran looks smart. | [S/L.V/sub-comp] |
| He was a doctor. | [S/L.V/sub-comp] |

তালিকা: be verb, become, feel, grow, look, remain, sound, seem, taste, stay, smell, turn ইত্যাদি।

> 💡 NB: এই verb গুলো একমাত্র তখনই linking verb হবে যদি এদের পরে subjective complement থাকে — নাহলে সাধারণ verb হতে পারে।

| | |
|---|---|
| Honey tastes sweet. | [sub/L.V/sub-comp] — Honey = sweet → এখানে linking verb |
| Jui tastes street food. | [sub/T.V/Obj] — street food = Object, Jui ≠ street food → এখানে linking verb নয়, সাধারণ transitive verb |

### 'Grow' — Linking বনাম Transitive

He grew old. → grew = became (অর্থে ব্যবহৃত), old = subjective complement → এখানে grow একটি linking verb।

He grew rice. → grew = cultivated/produced (অর্থে ব্যবহৃত), rice = Object → এখানে grow একটি transitive verb।

> 💡 একই verb প্রসঙ্গভেদে ভিন্ন ভূমিকা নেয় — পরের অংশটি Adjective/complement হলে linking, আর Noun/object হলে transitive।
