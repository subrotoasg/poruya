# পড়ুয়া — পরীক্ষা প্রস্তুতির স্ট্যাটিক সাইট

বিষয় (subject) → টপিক (topic) → অধ্যায় (section) → কার্ড (card) — এই চার স্তরে সাজানো।
সম্পূর্ণ স্ট্যাটিক: কোনো ডাটাবেস বা সার্ভার লাগে না, যেকোনো হোস্টিং-এ আপলোড করলেই চলবে।

## চালানো

```bash
node build.mjs          # কন্টেন্ট থেকে সব HTML তৈরি করে
python3 -m http.server  # লোকালি দেখতে
```

`node build.mjs` কোনো npm প্যাকেজ ছাড়াই চলে (Node 18+)।

## ফোল্ডার কাঠামো

```
public/
├── build.mjs                    # স্ট্যাটিক সাইট জেনারেটর
├── content/
│   ├── subjects.json            # সাইটের নাম + বিষয় ও টপিকের তালিকা
│   ├── topics/<topic-id>.json   # প্রতিটি টপিকের কন্টেন্ট
│   └── search-index.json        # (অটো-জেনারেটেড)
├── assets/css/style.css
├── assets/js/app.js
└── <subject-id>/<topic-id>/     # (অটো-জেনারেটেড HTML + Markdown)
```

`build.mjs` যেগুলো নিজে তৈরি করে — এগুলো হাতে এডিট করবেন না:
`index.html`, প্রতিটি `<subject>/` ও `<topic>/` ফোল্ডার, `sitemap.xml`,
`robots.txt`, `llms.txt`, `llms-full.txt`, `manifest.webmanifest`,
`assets/favicon.svg`, `content/search-index.json`।

## নতুন টপিক যোগ করা

**১.** `content/topics/` এ একটি নতুন JSON ফাইল বানান — যেমন `bd-geography.json`।

**২.** `content/subjects.json` এর ঐ বিষয়ের `topics` অ্যারেতে আইডিটি যোগ করুন
(অ্যারের ক্রম অনুযায়ীই সাইটে টপিক সাজানো হয়)।

**৩.** `node build.mjs` চালান। ব্যস।

## নতুন বিষয় যোগ করা

`content/subjects.json` এর `subjects` অ্যারেতে একটি অবজেক্ট যোগ করুন:

```json
{
  "id": "international-affairs",
  "name": "আন্তর্জাতিক বিষয়াবলি",
  "short": "আন্তর্জাতিক",
  "tagline": "ছোট এক লাইনের বর্ণনা",
  "description": "SEO ও সাবজেক্ট পেজের জন্য বড় বর্ণনা।",
  "topics": ["ia-un", "ia-organizations"]
}
```

তারপর `content/topics/ia-un.json` ইত্যাদি ফাইল বানিয়ে `node build.mjs` চালান।
হোম পেজ, মেনু, ফুটার, সাইটম্যাপ, সার্চ — সব নিজে থেকেই আপডেট হবে।

## টপিক ফাইলের ফরম্যাট

```json
{
  "id": "bd-geography",
  "subject": "bangladesh-affairs",
  "title": "বাংলাদেশের ভূগোল",
  "subtitle": "ঐচ্ছিক উপশিরোনাম",
  "description": "SEO ডেসক্রিপশন ও কার্ডে দেখানো হয়।",
  "keywords": ["ভূগোল", "নদী"],
  "sections": [
    {
      "id": "rivers",
      "title": "নদ-নদী",
      "cards": [
        { "id": "padma", "title": "পদ্মা", "blocks": [ ... ] }
      ]
    }
  ]
}
```

`id` গুলো URL-এর অ্যাঙ্কর হিসেবে ব্যবহৃত হয় — ইংরেজি, ছোট হাতের, হাইফেন দিয়ে
লিখুন এবং একবার প্রকাশের পর **বদলাবেন না** (পুরনো লিংক নষ্ট হবে)।

### ইনলাইন রঙ (স্লাইডের রঙের মতো)

যেকোনো টেক্সটের ভেতরে —

| লেখার নিয়ম | ফল | কখন ব্যবহার করবেন |
|---|---|---|
| `*টেক্সট*` | 🟡 সোনালি হাইলাইট | মুখস্থ করার মতো গুরুত্বপূর্ণ তথ্য, সাল, নাম |
| `_টেক্সট_` | 🟢 সবুজ | মূল ধারণা বা পরিভাষা |
| `` `টেক্সট` `` | 🔵 নীল (মনোস্পেস) | ইংরেজি শব্দ, সংখ্যা, গ্রন্থের নাম |

### ব্লকের ধরন

| `t` | গঠন | কাজ |
|---|---|---|
| `p` | `{"t":"p","v":"..."}` | সাধারণ অনুচ্ছেদ |
| `ul` | `{"t":"ul","v":["..",".."]}` | বুলেট তালিকা |
| `kv` | `{"t":"kv","v":[["নাম","মান"]]}` | দুই কলামের তথ্য-ছক |
| `note` | `{"t":"note","k":"শিরোনাম","v":"..."}` | নামযুক্ত বক্স (যেমন একজন রাজা) |
| `flow` | `{"t":"flow","v":["ক","খ","গ"]}` | তীরচিহ্নসহ ধারাবাহিক চিত্র |
| `tip` | `{"t":"tip","v":"..."}` | 💡 মনে রাখার সূত্র / গুরুত্বপূর্ণ নোট |
| `table` | `{"t":"table","c":"ক্যাপশন","h":["ক","খ"],"v":[["১","২"]]}` | বড় ছক (মোবাইলে কার্ডে ভেঙে যায়) |
| `quiz` | নিচে দেখুন | ইন্টারঅ্যাক্টিভ MCQ |

**কুইজ:**

```json
{
  "t": "quiz",
  "q": "প্রশ্ন?",
  "src": "BCS 44th",
  "v": ["অপশন ক", "অপশন খ", "অপশন গ", "অপশন ঘ"],
  "a": 2,
  "note": "উত্তরের ব্যাখ্যা (ঐচ্ছিক)"
}
```

`a` হলো সঠিক উত্তরের ইনডেক্স — **০ থেকে শুরু** (অর্থাৎ `2` মানে তৃতীয় অপশন 'গ')।
`src` ও `note` ঐচ্ছিক।

## যা তৈরি আছে

- **ডার্ক / লাইট / সিস্টেম থিম** — হেডারের বাটন বা `t` চাপলে বদলায়, মনে রাখে
- **সার্চ** — `/` বা `Ctrl/Cmd+K`; সব কার্ডের ভেতরের লেখাতেও খোঁজে
- **পড়া হয়েছে / বুকমার্ক / লিংক কপি** — প্রতিটি কার্ডে, ব্রাউজারে সংরক্ষিত থাকে
- **কীবোর্ড** — `j`/`k` পরের/আগের কার্ড, `/` সার্চ, `t` থিম, `esc` বন্ধ
- **সূচিপত্র** — ডেস্কটপে সাইডবার (স্ক্রল করলে হাইলাইট হয়), মোবাইলে ড্রয়ার
- **রেসপন্সিভ** — ৩২০px থেকে বড় ডেস্কটপ পর্যন্ত; বড় ছক মোবাইলে কার্ডে ভাঙে
- **প্রিন্ট** — আলাদা স্টাইলশিট, নোট প্রিন্ট করলে পরিষ্কার দেখায়

### SEO ও AI এজেন্ট

- প্রতিটি পাতায় `title`, `description`, `canonical`, `keywords`, OpenGraph, Twitter Card
- JSON-LD: `WebSite`, `ItemList`, `Article`, `BreadcrumbList`, `LearningResource`
- `sitemap.xml` · `robots.txt` (GPTBot, ClaudeBot, PerplexityBot, Google-Extended allow করা)
- `llms.txt` — AI এজেন্টের জন্য সাইটের মানচিত্র
- `llms-full.txt` — সম্পূর্ণ কন্টেন্ট এক ফাইলে
- প্রতিটি টপিকের প্লেইন-টেক্সট সংস্করণ — URL-এর শেষে `index.md`
- `content/search-index.json` — পুরো কন্টেন্ট JSON API হিসেবে

### প্রকাশের আগে

`content/subjects.json` এর `site.url` আপনার আসল ডোমেইনে বদলে নিন —
sitemap, canonical ও llms.txt এর লিংক এখান থেকেই তৈরি হয়। তারপর `node build.mjs`।
